# AutoByteus

**An open-source, local-first workspace for AI agents, teams, and organizations.**

Work with an individual agent, bring specialists together in a team, or organize multiple agents and teams into an AI organization. AutoByteus brings these workflows into one desktop workspace, with reusable skills and access to your own tools and files.

Use it for software development, research, writing, and content creation—or build custom applications on top of its agent runtime.

## What you can do

- **Work with agents and teams.** Define specialist roles, coordinate tasks, and reuse teams across workflows.
- **Build AI organizations.** Bring individual agents and reusable teams together, with explicit handoffs between them.
- **Extend agents with skills.** Import reusable skills or create your own instructions and supporting tools.
- **Work locally or connect your own nodes.** Use the desktop's bundled server or connect to a server over a trusted private network, with paired phone access when you need it.
- **Build custom applications.** Create purpose-built interfaces and backend logic on top of the AutoByteus runtime.
